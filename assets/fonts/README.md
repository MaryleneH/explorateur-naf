# Excalifont

`Excalifont-Regular.woff2` est le sous-ensemble latin de la police manuscrite
**Excalifont**, créée par l'équipe Excalidraw.

- Origine : paquet npm [`@excalidraw/excalidraw`](https://www.npmjs.com/package/@excalidraw/excalidraw)
  version 0.18.0 (licence MIT), fichier
  `dist/prod/fonts/Excalifont/Excalifont-Regular-a88b72a24fb54c9f94e3b5fdaa7481c9.woff2`.
- Couverture : Basic Latin + Latin-1 (accents français inclus), ~25 Ko.
- Usage dans ce site : police d'**accent** pour les annotations pédagogiques
  (classe `.naf-hand`), jamais comme police principale.
- Repli : si la police ne charge pas, la pile de secours
  (`"Segoe Print", "Bradley Hand", cursive`) prend le relais — aucune
  information n'en dépend.
